# ScrapBook da Bia 🌷

Scrapbook pessoal com folhas diárias, fontes e cores de texto, papéis delicados, adesivos e fotos.

## Como usar

Abra `index.html` em um navegador ou publique os dois arquivos em uma hospedagem estática, como GitHub Pages. Não há instalação de dependências nem etapa de build.

As memórias são salvas no armazenamento local do navegador. Não há sincronização entre dispositivos. Limpar os dados do navegador remove as memórias. As fontes do Google Fonts precisam de internet; fontes alternativas são usadas quando indisponíveis.

## Arquivos

- `index.html`: interface e estilos responsivos.
- `app.js`: editor, folhas, fotos e salvamento local.
